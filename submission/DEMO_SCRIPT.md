# STUDYFLOW AI — Demo Script

Target duration: 2–3 minutes.

## 1. Opening (15–20 seconds)

"Students often have lecture notes, but turning those notes into something they can understand and practise takes time. STUDYFLOW AI is a learning workspace that turns course materials into explanations, revision notes, and quizzes."

## 2. Add study material (20–30 seconds)

- Open the application.
- Upload a short, text-based lecture note or paste a prepared excerpt.
- Point out the document name and extracted text status.

## 3. Simplify a topic (30–40 seconds)

- Select Simplify a topic.
- Enter a topic from the source material.
- Generate the explanation.
- Show how the result defines terms and explains the concept in student-friendly language.

## 4. Generate a quiz (30–40 seconds)

- Select Generate a quiz.
- Generate the multiple-choice questions.
- Answer the questions and submit.
- Show the score and explanations.

## 5. Close (15–20 seconds)

"STUDYFLOW AI helps students move from reading notes to understanding and practising them. The goal is not to replace learning, but to make the material easier to work with."

## Demo preparation checklist

- Use a short sample document with clear, selectable text.
- Configure the Gemini key in the deployment environment before recording.
- Test the exact workflow on the deployed URL.
- Do not show API keys, private documents, or personal account information.
- Only demonstrate features that are implemented and verified.
