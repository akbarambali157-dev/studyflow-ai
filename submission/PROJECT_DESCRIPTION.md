# STUDYFLOW AI — Hackathon Project Description

## Short description

STUDYFLOW AI is an AI-powered learning workspace that transforms students' lecture materials into clear explanations, concise revision notes, and interactive practice questions. Students begin with their own course content instead of a generic chatbot conversation, then choose the learning activity that best supports their next step.

## Problem

Students regularly work with long, dense lecture notes in PDF, Word, and text formats. Turning those materials into understandable explanations, revision notes, and practice questions takes time and can make revision feel fragmented.

## Solution

STUDYFLOW AI brings those activities into one responsive web application. A student uploads or pastes study material, selects a task, and receives an AI-generated result grounded in the supplied content. The aim is to make learning more active: understand a concept, condense it into revision notes, and test understanding with questions.

## Core experience

1. Add course material.
2. Choose a learning task.
3. Generate a source-aware explanation, revision summary, or quiz.
4. Review the output and compare important details with the original notes.

## Technology

- Next.js App Router and React
- TypeScript
- Tailwind CSS
- Google Gemini API through server-side route handlers
- PDF and DOCX text extraction
- Vercel deployment
